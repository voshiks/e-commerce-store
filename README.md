**E-Commerce Store**
Cílem tohoto projektu je vytvořit webovou aplikaci typu ECommerce Store s administrátorským rozhraním. Systém umožní uživatelům
procházet produkty, přidávat je do košíku a vytvářet objednávky. Pro správu eshopu bude k dispozici administrátorská část s funkcemi pro správu produktů,
kategorií, kupónů a analýzu prodejů.
